 TypeScript: JavaScript'in üzerine bir "type system" eklenerek oluşturulmuş bir dildir. Yeni ve bağımsız bir dil değildir.
 JavaScript'in tamamını içerir ve ona tip bilgisini ekler.

// Interface Tanım: Interface, bir object'in hangi property'lere sahip olacağını ve her property'nin tipinin ne olduğunu tanımlar.
Tanım iki: Interface, bir veri yapısının sahip olması gereken property'leri ve bu property'lerin tiplerini tanımlayan bir sözleşmedir.
Kendisi veri tutmaz; yalnızca verinin nasıl görünmesi gerektiğini belirtir.

interface Student {
    name: string;   // Student interface'i
    grade: number;
}

Interface tanımlandıktan sonra bir variable'ın tipi olarak kullanılır.

const student: Student = {
    name: "Ali",  // Interface'in kullanımı
    grade: 3
};

// Interface adları büyük harfle başlar ve tekil yazılır. Property'lerin arası noktalı virgülle ayrılır.

map(): array'in her element'i için bir şey üretir. Hafta birde map() ile sayı veya metin üretirken artık component üretiyoruz.

Tanım key: key, bir liste içindeki her elemente verilen benzersiz değerdir. React'in listedeki elementleri birbirinden ayırt etmesine yardım eder.

key için verinin kendi benzersiz alanı kullanılır. Genellikle bu id olur.

key verilmeden de uygulama çalışır ancak uzun vadede sorunlara yol açar.

Tanım state: State, bir component'in zaman içerisinde değişebilen verisidir. Component kendi state'ini oluşturur,
okur ve günceller. State değiştiğinde component yeniden render edilir ve ekranda yeni değer görünür.

State oluşturmak için useState function'ı gereklidir. react paketinden import edilir.
import {useState} from "react";


State şu satırla oluşturulabilir.

const [count, setCount] = useState(0);
